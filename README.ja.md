## ButtSnap とは？

ButtSnap は、日常の一瞬を美しいステッカーに変えるアプリです。道端で見つけた小さな花、カフェで頼んだ可愛いラテアート、お気に入りのキーホルダー…カメラを向けてシャッターを押すだけで、アプリが自動的に被写体を認識し、ふんわりとした白枠と輝きのある素敵なステッカーに仕上げます。

アカウント不要。写真のアップロードも不要。すべてはあなたの端末の中で完結します。

## ✨ 主な機能

- **スナップでステッカー** — 気になるものを撮影するだけで、アプリが自動でステッカーを生成
- **日ごとのステッカー日記** — すべてのステッカーが日付ごとに整理され、日記のように振り返れます
- **テーマ別コレクション** — 「街歩き」「コーヒー巡り」「かわいい車」など、自由にコレクションを作成
- **クリエイティブキャンバス** — ステッカーを自由に組み合わせてコラージュやステッカーウォールを作り、友達と共有
- **完全プライベート** — すべての処理は端末上で実行。写真が外部に送信されることは一切ありません。アカウント登録も不要
