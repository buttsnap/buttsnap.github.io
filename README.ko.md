## ButtSnap이란?

ButtSnap은 일상의 순간을 아름다운 스티커로 바꿔주는 앱입니다. 길가의 작은 꽃, 카페의 귀여운 컵, 마음에 드는 키링 등… 관심 있는 물건에 카메라를 향하고 셔터를 누르면, 앱이 자동으로 피사체를 인식해 부드러운 흰색 테두리와 은은한 광택이 있는 예쁜 스티커로 만들어 줍니다.

계정도, 업로드도 필요 없습니다. 모든 것이 내 기기 안에서 이루어집니다.

## ✨ 주요 기능

- **스냅 한 번에 스티커** — 주변의 어떤 것이든 촬영하면 앱이 자동으로 스티커 생성
- **일간 스티커 다이어리** — 모든 스티커가 날짜별로 정리되어 일기처럼 모아볼 수 있습니다
- **테마 컬렉션** — 「도시 산책」「커피 기록」「귀여운 자동차」등 자유롭게 컬렉션을 만들어 분류
- **자유로운 캔버스** — 스티커를 자유롭게 조합해 콜라주나 스티커 월을 만들고 친구들과 공유
- **완전한 프라이버시** — 모든 처리가 기기 내에서 로컬로 실행됩니다. 사진이 외부로 전송되지 않으며 계정 등록도 불필요
