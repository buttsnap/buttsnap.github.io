## 反馈注意事项

为了让反馈更快被处理，请尽量提供详细信息：

### Bug 报告

提交 Bug 报告时，请尽可能包含以下信息：

- **iOS 版本**：在「设置 → 通用 → 关于本机」中查看
- **App 版本**：在 ButtSnap「设置」页面中查看
- **复现步骤**：详细描述做了什么操作后出现的问题（比如「用相册选了一张花朵照片生成贴纸，主体被切了一半」）
- **期望结果**：描述你期望的正确行为
- **截图**：附上贴纸效果截图或问题界面截图，帮助巨大！

### 功能建议

提出功能建议时，可以想想这些：

- 你希望这个功能解决什么场景下的需求？
- 你平时遇到什么情况时会想起「要是 ButtSnap 能这样就好了」？
- 有没有在其他 App 里见过类似功能，可以作为参考？
