## 2. 服務說明

ButtSnap 是一款貼紙收藏 App，可讓你拍攝日常物件與瞬間，並自動轉換成可收藏的貼紙。核心功能包括：

- 一拍成貼：拍攝主體後，自動分離並套用貼紙樣式
- 按日期整理的貼紙時間線
- 用於分類與整理的主題收藏集
- 用於建立拼貼與貼紙牆的畫布
- 用於完整掌控收藏的資料匯出與匯入

ButtSnap Pro 是可選的自動續訂訂閱，可解鎖無限每日拍攝與進階背景。訂閱完全透過你的 Apple ID 管理。
