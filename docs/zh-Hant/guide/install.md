# 開始使用

## 下載

ButtSnap 可在 App Store 下載。打開 App Store 搜尋「ButtSnap」，或點擊下方連結下載。

[![Download on the App Store](https://developer.apple.com/assets/elements/badges/download-on-the-app-store.svg)](https://apps.apple.com/app/id6762453848)

## 系統需求

- iOS 26.0 或以上
- 支援 iPhone 與 iPad

## 第一次啟動

### 1. 打開 App

安裝完成後，點擊主畫面上的 ButtSnap 圖示即可啟動。你會先看到親切的品牌角色，準備開始收藏生活裡的小驚喜。

### 2. 授權權限

第一次啟動時，App 會請求以下權限：

- **相機**：用來拍攝你想收藏的物件，請點選「允許」
- **照片圖庫**：用來將貼紙儲存到裝置，請點選「允許」

就這樣。ButtSnap 不需要帳號、Email 或其他個人資訊。所有處理都在你的裝置上完成。

### 3. 開始收藏

你已經準備好了。把相機對準有趣的小物，拍下第一張照片，App 會自動生成你的第一枚貼紙。

之後如果想管理訂閱或匯出資料，可以在 App 內的「個人」頁面操作。
