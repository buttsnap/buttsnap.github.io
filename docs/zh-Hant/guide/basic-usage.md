# 基本使用

## 拍出貼紙

ButtSnap 的核心，是把日常瞬間變成值得收藏的貼紙。

### 拍一張照片

1. 打開 App，你會直接看到相機畫面
2. 找到有趣的主體，例如小紀念品、漂亮葉子、可愛杯子或特別的鑰匙圈
3. 對準主體並點擊快門
4. ButtSnap 會自動分離主體、去除背景，並加上白色邊框與柔和光暈
5. 新貼紙會立即出現在你的時間線中

### 做出好看貼紙的小技巧

- **光線充足**：自然光或明亮環境可以讓邊緣更乾淨
- **背景簡單**：單一且明確的主體通常效果最好
- **保持穩定**：拍攝時手不要晃，成品會更清晰
- **嘗試不同角度**：桌面小物很適合用俯拍方式
- **使用相簿照片**：也可以從相簿選擇舊照片生成貼紙

## 瀏覽時間線

所有貼紙會自動按日期整理，就像一本貼紙日記。

### 時間線視圖

打開 App 主頁，你會看到貼紙依日期分組：

- 每個日期會顯示當天生成的所有貼紙
- 左右滑動可以瀏覽不同日期
- 像翻日記一樣重溫你收藏的小瞬間

### 查看貼紙詳情

點擊任一貼紙即可查看細節。你可以：

- **刪除**：不滿意的貼紙可以刪除
- **加入收藏集**：把貼紙分類到指定收藏集
- **匯出**：將貼紙儲存到系統相簿或分享給朋友

## 分享貼紙

- 點擊貼紙進入詳情頁，然後點擊分享按鈕
- 可以透過訊息、社群 App 分享，也可以儲存到照片圖庫
- 匯出的貼紙會保留白邊與光暈效果，在任何地方都很好看
