# 進階功能

## 收藏集

收藏集可以把相關貼紙放在一起，適合整理主題系列，也適合用貼紙講故事。

### 建立收藏集

1. 點擊「收藏集」分頁
2. 點擊「+」建立新收藏集
3. 輸入名稱，例如「城市漫步」「咖啡杯」「可愛小車」
4. 點擊「完成」

### 將貼紙加入收藏集

1. 從時間線打開任一貼紙
2. 點擊「加入收藏集」
3. 選擇想加入的收藏集，貼紙就會立即加入

同一枚貼紙可以加入多個收藏集。咖啡杯貼紙可以同時屬於「咖啡杯」和「早晨發現」。

### 管理收藏集

- **重新命名**：點擊收藏集名稱即可編輯
- **重新排序**：長按並拖曳收藏集
- **刪除**：向左滑動收藏集即可移除。你的貼紙不會被刪掉，只會移除這個分類

## 畫布

畫布是讓貼紙自由組合的創作空間。

### 建立拼貼

1. 點擊「畫布」分頁
2. 點擊「新增畫布」
3. 點擊「加入貼紙」選擇要使用的貼紙
4. 拖曳、縮放、旋轉，調整每枚貼紙的位置
5. 用背景選擇器挑選畫布背景色或紋理

### 畫布小技巧

- **堆疊層次**：把貼紙疊在一起，可以做出更有層次的畫面
- **主題貼紙牆**：用同一個收藏集的貼紙填滿畫布
- **匯出分享**：完成後可以匯出成圖片，或直接分享給朋友

## 資料管理

### 匯出你的收藏

資料屬於你。你可以隨時匯出完整貼紙收藏：

1. 前往「個人 → 資料」
2. 點擊「匯出資料」
3. 選擇儲存位置。匯出的資料包含所有貼紙與相關資訊
4. 可用於備份、換機或保存一份安全副本

### 匯入你的收藏

1. 前往「個人 → 資料」
2. 點擊「匯入資料」
3. 選擇之前匯出的備份檔
4. 貼紙與收藏集會被完整還原

### 儲存空間說明

- 貼紙只儲存在你的裝置上，ButtSnap 不會上傳到雲端
- 如果刪除 App，App 內貼紙資料也會被移除。重新安裝前建議先匯出備份
- App 本身佔用空間很少，主要容量來自你保存的貼紙圖片

## Pro 訂閱

ButtSnap 的核心功能可免費使用，並提供每日貼紙建立額度。如果你想要：

- **無限貼紙**：移除每日拍攝和貼紙生成限制
- **更多精美背景**：解鎖 Pro 專屬貼紙背景樣式

可以訂閱 ButtSnap Pro。訂閱會透過你的 Apple ID 管理，也可以隨時在系統設定中取消。
