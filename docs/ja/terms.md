## 二、サービスの説明

本アプリはステッカー収集・創作ツールであり、以下のコア機能を提供します：

- 写真を撮影し、端末上のローカル認識によってステッカーを生成
- 日付ごとにステッカーコレクションを整理・閲覧
- テーマ別コレクションを作成してステッカーを管理
- キャンバス上でステッカーを自由に組み合わせてコラージュ作品を創作
- データのエクスポートとインポート、データ移行のサポート

本アプリの基本機能は無料でご利用いただけます。一部の高度な機能（ステッカー作成数無制限、Pro限定の背景スタイルなど）は、Proサブスクリプションを通じてアンロックされます。

当社は、本アプリの機能を随時変更または中断する権利を留保します。

## 三、Proサブスクリプション条項

ProサブスクリプションはApple App Storeのアプリ内課金システムを通じて提供されます：

1. サブスクリプション料金はApp Storeの表示価格に準じ、地域によって異なる場合があります
2. サブスクリプションは自動更新され、現在の期間終了の少なくとも24時間前までにキャンセルされない限り継続されます
3. 更新料金は現在の期間終了の24時間前までにお客様のApple IDアカウントに請求されます
4. iPhoneの「設定 → Apple ID → サブスクリプション」からいつでもサブスクリプションの管理・解約が可能です
5. サブスクリプションをキャンセルした後も、現在の課金期間中はPro機能が引き続き有効です。期間終了後、自動的に無料版の機能に戻ります
6. 作成済みのステッカーとコレクションは、サブスクリプション終了後も失われることはありません
