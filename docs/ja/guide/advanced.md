# 高度な機能

## コレクション

コレクションを使うと、関連するステッカーをグループにまとめられます — テーマ別のセットを整理して物語を紡ぐのに最適です。

### コレクションを作成する

1. コレクションタブをタップ
2. 「+」ボタンをタップして新しいコレクションを作成
3. 名前をつけましょう — 「街歩き」「コーヒーカップ」「かわいい車」など、楽しい名前で
4. 「完了」をタップ

### ステッカーをコレクションに追加する

1. タイムラインから任意のステッカーを開く
2. 「コレクションに追加」をタップ
3. 追加したいコレクションを選択 — ステッカーはすぐに追加されます

同じステッカーを複数のコレクションに追加することもできます。コーヒーカップのステッカーは「コーヒーカップ」と「朝の発見」の両方に属することができます！

### コレクションを管理する

- **名前変更**：コレクション名をタップして編集
- **並べ替え**：長押ししてドラッグでコレクションの順序を変更
- **削除**：コレクションを左にスワイプして削除（ステッカーは安全です — グループ分けだけが解除されます）

## キャンバス

キャンバスは、ステッカーが集まるクリエイティブな遊び場です。

### コラージュを作成する

1. キャンバスタブをタップ
2. 「新規キャンバス」をタップして白紙のキャンバスを開始
3. 「ステッカーを追加」をタップしてコレクションからステッカーを選択
4. ドラッグ、ピンチ、回転で各ステッカーを思い通りに配置
5. 背景ピッカーでキャンバスの背景色やテクスチャを選択

### キャンバスのコツ

- **レイヤーを重ねる**：ステッカーを重ねて奥行きを演出
- **テーマ別ウォール**：ひとつのコレクションのステッカーでキャンバスを埋め尽くして「ステッカーウォール」を作成
- **書き出しと共有**：満足したら、エクスポートをタップして作品を画像として保存したり、そのまま共有したり

## データ管理

### コレクションをエクスポートする

データはあなたのものです。ステッカーコレクション全体をいつでもエクスポートできます：

1. 「個人」→「データ」に移動
2. 「すべてのデータを書き出す」をタップ
3. 保存先を選択 — エクスポートされたコレクションにはすべてのステッカーとメタデータが含まれます
4. バックアップ、新しい端末への移行、安全なコピーの保管にご活用ください

### コレクションをインポートする

1. 「個人」→「データ」に移動
2. 「バックアップから読み込む」をタップ
3. 以前にエクスポートしたバックアップファイルを選択
4. ステッカーとコレクションが復元されます

### ストレージについて

- ステッカーは端末内に保存されます。ButtSnapがクラウドにアップロードすることはありません
- アプリを削除すると、ステッカーも削除されます。再インストール予定がある場合は、事前にバックアップをエクスポートすることをおすすめします
- アプリ自体の容量はごくわずか — 容量を使うのはステッカー画像だけです

## Pro 購読

ButtSnapの基本機能は無料でご利用いただけますが、1日あたりのステッカー作成数に上限があります。以下のような方はProへのアップグレードをご検討ください：

- **ステッカーを無制限に作成**：1日の撮影・ステッカー生成数の制限を解除
- **より多くの美しい背景**：Pro限定のステッカー背景スタイルをアンロック

ButtSnap ProのサブスクリプションはApple IDを通じて管理され、システム設定からいつでもキャンセルできます。
