# 基本操作

## ステッカーを撮る

ButtSnapの核心は、日常の瞬間をコレクションステッカーに変えることです。その仕組みは次のとおりです：

### 撮影する

1. アプリを開くと、すぐにカメラのファインダーが表示されます
2. 面白いものを見つけましょう：小さなお土産、きれいな花、かわいいカップ、ユニークなキーホルダー
3. 被写体にカメラを向けて、シャッターボタンをタップ
4. ButtSnapが自動的にメインの被写体を切り抜き、背景を除去し、美しい白いフチとふんわりとした光彩を適用します
5. 新しいステッカーがすぐにタイムラインに表示されます

### きれいなステッカーを撮るコツ

- **十分な明るさを**：自然光または十分に明るいシーンで撮ると、最もきれいなステッカーに仕上がります
- **シンプルに**：ひとつのはっきりした被写体が最適です — 雑多なシーンではなく、一つの対象物を意識してください
- **手ブレに注意**：撮影中はしっかりと構えて、最もシャープな結果を目指しましょう
- **角度を楽しむ**：テーブルの上の小さなものを真上から撮ると、満足感のあるフラットレイステッカーになります
- アルバムから既存の写真を選んでステッカーを作成することもできます

## タイムラインを見る

ステッカーは日付ごとに整理され、ビジュアル日記のようになっています：

- **日付をスクロール**：左右にスワイプして、コレクションを日ごとに巡りましょう
- **一日を一目で**：各日付にその日に作成したステッカーがきれいなグリッドで表示されます
- **ステッカーをタップ**：任意のステッカーを開いて、詳細表示で拡大して鑑賞できます。また、以下の操作も可能です：
  - **削除**：ステッカーに満足できない場合は、直接削除できます
  - **コレクションに追加**：ステッカーを作成したコレクションに分類できます
  - **書き出し**：ステッカーをフォトライブラリに保存したり、友達と共有したりできます

タイムラインはあなただけのステッカーダイアリー — 撮影したすべての日がコレクションの1ページになります。

## ステッカーを共有する

- 任意のステッカーをタップして詳細表示を開き、共有ボタンをタップ
- メッセージやSNSで友達と共有したり、フォトライブラリに保存したりできます
- 書き出したステッカーは白いフチと光彩効果を保ったまま — どこでもきれいに映えます

サブスクリプションの管理やデータのエクスポートは、アプリ内の「個人」ページから行えます。
