# はじめに

## ダウンロード

ButtSnapはApp Storeから入手できます。App Storeを開いて「ButtSnap」と検索するか、下のリンクをタップしてダウンロードしてください。

[![Download on the App Store](https://developer.apple.com/assets/elements/badges/download-on-the-app-store.svg)](https://apps.apple.com/app/buttsnap/id0000000000)

## システム要件

- iOS 16.0以降
- iPhoneおよびiPadに対応

## 初回起動

### 1. アプリを開く

インストールが完了したら、ホーム画面のButtSnapアイコンをタップして起動します。フレンドリーなコーギーマスコットがお出迎えします — よろしくね！

### 2. 権限を許可する

初回起動時に、アプリは以下の権限をリクエストします：

- **カメラ**：発見したものを撮影するために必要です。「許可」をタップしてください
- **フォトライブラリ**：ステッカーを端末に保存するために必要です。「許可」をタップしてください

以上です！ButtSnapはアカウントもメールアドレスも、その他何も必要としません。すべての処理は端末上で直接行われるため、登録するものは一切ありません。

### 3. コレクションを始める

準備完了です！気になるものにカメラを向けて、最初の1枚を撮影しましょう。アプリが自動的に最初のステッカーを作成します — それだけ簡単です。
