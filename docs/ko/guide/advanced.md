# 고급 기능

## 컬렉션

컬렉션을 사용하면 관련 스티커를 함께 그룹화할 수 있습니다 — 테마 세트를 큐레이션하고 이야기를 전달하는 데 완벽합니다.

### 컬렉션 만들기

1. 컬렉션 탭을 탭하세요
2. "+" 버튼을 탭하여 새 컬렉션을 만드세요
3. 이름을 지정하세요 — '도시 산책', '커피잔', '귀여운 자동차' 같은 재미있는 이름으로요
4. "완료"를 탭하세요

### 컬렉션에 스티커 추가하기

1. 타임라인에서 아무 스티커나 열어보세요
2. "컬렉션에 추가"를 탭하세요
3. 원하는 컬렉션을 선택하세요 — 스티커가 즉시 추가됩니다

같은 스티커를 여러 컬렉션에 추가할 수 있습니다. 커피잔 스티커 하나가 '커피잔'과 '아침 발견' 두 컬렉션에 동시에 속할 수 있어요!

### 컬렉션 관리하기

- **이름 변경**: 컬렉션 이름을 탭하여 편집하세요
- **순서 변경**: 길게 누르고 드래그하여 컬렉션을 재정렬하세요
- **삭제**: 컬렉션을 왼쪽으로 스와이프하여 제거하세요 (스티커는 안전합니다 — 그룹만 제거됩니다)

## 캔버스

캔버스는 스티커들이 하나로 모이는 창의적인 놀이터입니다.

### 콜라주 만들기

1. 캔버스 탭을 탭하세요
2. "새 캔버스"를 탭하여 빈 캔버스로 시작하세요
3. "스티커 추가"를 탭하여 컬렉션에서 스티커를 선택하세요
4. 드래그, 핀치, 회전으로 각 스티커를 원하는 대로 배치하세요
5. 배경 선택기를 사용해 캔버스 배경 색상이나 텍스처를 선택하세요

### 캔버스 팁

- **겹쳐보세요**: 스티커를 서로 위에 배치하여 깊이감을 만들어보세요
- **테마 월**: 단일 컬렉션의 스티커로 캔버스를 가득 채워 '스티커 월'을 만들어보세요
- **내보내기 & 공유**: 마음에 들면 내보내기를 탭하여 작품을 이미지로 저장하거나 바로 공유하세요

## 데이터 관리

### 컬렉션 내보내기

여러분은 데이터의 주인입니다. 언제든지 전체 스티커 컬렉션을 내보낼 수 있습니다:

1. 프로필 → 설정으로 이동하세요
2. "데이터 내보내기"를 탭하세요
3. 저장 위치를 선택하세요 — 내보낸 컬렉션에는 모든 스티커와 메타데이터가 포함됩니다
4. 백업, 새 기기로 마이그레이션, 또는 안전한 사본 보관 용도로 사용하세요

### 컬렉션 가져오기

1. 프로필 → 설정으로 이동하세요
2. "데이터 가져오기"를 탭하세요
3. 이전에 내보낸 백업 파일을 선택하세요
4. 스티커와 컬렉션이 복원됩니다

### 저장 공간 참고사항

- 스티커는 기기에 저장됩니다. ButtSnap은 클라우드에 아무것도 업로드하지 않습니다
- 앱을 삭제하면 스티커도 제거됩니다. 재설치를 계획 중이라면 백업을 내보내는 것을 권장합니다
- 앱 자체는 저장 공간을 거의 사용하지 않습니다 — 스티커 이미지만 공간을 차지합니다
