# 기본 사용법

## 스티커 촬영하기

ButtSnap의 핵심은 일상의 순간을 수집 가능한 스티커로 바꾸는 것입니다. 작동 방식을 알아볼까요:

### 사진 찍기

1. 앱을 열면 바로 카메라 뷰파인더가 표시됩니다
2. 흥미로운 무언가를 찾아보세요: 작은 기념품, 예쁜 꽃, 귀여운 컵, 독특한 키링
3. 카메라를 피사체에 향하고 셔터 버튼을 탭하세요
4. ButtSnap이 자동으로 주요 피사체를 분리하고, 배경을 제거한 후 부드러운 글로우 효과와 함께 아름다운 흰색 테두리를 적용합니다
5. 새로운 스티커가 즉시 타임라인에 나타납니다

### 멋진 스티커를 위한 팁

- **좋은 조명이 도움됩니다**: 자연광이나 밝은 장면에서 가장 깔끔한 스티커가 만들어집니다
- **단순하게 유지하세요**: 단일하고 뚜렷한 피사체가 가장 잘 작동합니다 — 복잡한 장면보다 하나의 대상을 생각하세요
- **손을 고정하세요**: 가장 선명한 결과를 위해 촬영할 때 안정적으로 유지하세요
- **각도를 바꿔보세요**: 탁자 위의 작은 물체를 위에서 내려다보며 촬영하면 만족스러운 플랫레이 스티커를 만들 수 있습니다
- **앨범에서 선택**: 앨범에서 기존 사진을 선택하여 스티커를 만들 수도 있습니다

## 타임라인 탐색하기

스티커는 날짜별로 정리되어, 마치 비주얼 다이어리와 같습니다:

- **날짜별로 스크롤**: 위아래로 스와이프하여 컬렉션을 하루하루 여행하세요
- **하루를 한눈에**: 각 날짜는 그날 만든 모든 스티커를 깔끔한 그리드로 보여줍니다
- **스티커 탭하기**: 아무 스티커나 탭하면 확대하여 자세히 볼 수 있으며, 다음 작업을 수행할 수 있습니다:
  - **삭제**: 스티커가 마음에 들지 않으면 바로 삭제할 수 있습니다
  - **컬렉션에 추가**: 스티커를 만든 컬렉션에 분류할 수 있습니다
  - **내보내기**: 스티커를 앨범에 저장하거나 친구에게 공유할 수 있습니다
- **길게 누르기**: 스티커를 길게 누르면 복사, 공유, 삭제가 가능합니다

타임라인은 여러분의 개인 스티커 일기입니다 — 무언가를 촬영한 하루하루가 컬렉션의 한 페이지가 됩니다.

## 스티커 공유하기

- 아무 스티커나 탭하여 상세 보기로 연 다음, 공유 버튼을 탭하세요
- 메시지, 소셜 미디어를 통해 친구들과 개별 스티커를 공유하거나 사진 라이브러리에 저장하세요
- 내보낸 스티커는 흰색 테두리와 글로우 효과가 그대로 유지됩니다 — 어디서나 멋지게 보여요
