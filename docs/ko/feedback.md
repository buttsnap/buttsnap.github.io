## 효과적인 피드백을 위한 팁

### 버그 신고

버그를 신고할 때는 다음 정보를 포함해 주세요:

- **iOS 버전**: 설정 → 일반 → 정보에서 확인
- **앱 버전**: ButtSnap '개인'에서 확인
- **발생한 현상**: 무엇을 하고 있었고, 어떤 문제가 발생했는지 설명
- **기대한 동작**: 어떻게 작동했어야 하는지 설명
- **스크린샷**: 관련이 있다면 문제를 보여주는 스크린샷을 첨부해 주세요 — 특히 스티커 품질 문제에 도움이 됩니다

### 기능 제안

기능을 제안할 때는 다음 내용을 공유해 주시면 좋습니다:

- 현재는 할 수 없지만, 스티커로 하고 싶은 일이 있나요?
- 이 기능이 여러분의 수집 또는 공유 습관에 어떻게 어울릴까요?
- 아이디어에 영감을 준 다른 앱의 예시가 있나요?
