# 进阶功能

## 创建合集

当你的贴纸越来越多，合集功能可以帮助你更有条理地整理它们。

### 新建合集

1. 进入「合集」页面
2. 点击「新建合集」
3. 给合集起一个名字，比如「城市漫步」「咖啡打卡」「可爱小车」
4. 选择一枚封面贴纸
5. 创建完成！

### 管理合集

- **添加贴纸**：在贴纸详情页中，选择「加入合集」并勾选目标合集
- **移除贴纸**：进入合集，长按贴纸选择移除
- **编辑合集**：修改合集名称、更换封面、删除整个合集（不会删除贴纸本身）

合集让你的收藏更有主题感，也方便你向朋友展示某一类贴纸——比如「给你看我这周拍的所有猫猫！」

## 画布拼贴

画布功能让你能把多枚贴纸自由组合，创造独一无二的拼贴作品。

### 创建拼贴

1. 进入「画布」页面，点击新建画布
2. 从你的贴纸库中选取贴纸，拖入画布
3. 自由调整每枚贴纸的位置、大小和旋转角度
4. 可以叠加摆放，创造出丰富的层次感

### 导出作品

完成拼贴后，点击导出按钮，即可将整张画布保存为高清图片。你可以：

- 保存到相册
- 直接分享到社交平台
- 导出后用作手机壁纸

无论是做旅行手帐、日常记录，还是纯粹觉得好玩，画布都能给你充分的创作自由。

## 数据导出与导入

ButtSnap 完全支持数据迁移，你的贴纸永远属于你。

### 导出全部数据

在「设置」→「数据管理」中，点击「导出数据」：

- 所有贴纸图片会以原图质量导出
- 合集结构和分类信息会一并保留
- 导出为一个压缩包，可以保存到文件 App 或发送到电脑

### 导入数据

换新手机了？从旧设备导出的数据包，可以在新设备的 ButtSnap 中一键导入，所有贴纸和合集结构都会完整还原。
