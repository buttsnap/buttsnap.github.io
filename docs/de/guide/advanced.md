# Erweiterte Funktionen

## Sammlungen

Sammlungen helfen dir, zusammengehorige Sticker zu gruppieren, etwa fur Themen, Orte oder kleine Geschichten.

### Eine Sammlung erstellen

1. Tippe auf den Tab Sammlungen
2. Tippe auf die Schaltflache "+"
3. Vergib einen Namen, zum Beispiel "Stadtspaziergang", "Kaffee" oder "Kleine Funde"
4. Tippe auf "Fertig"

### Sticker hinzufugen

1. Offne einen Sticker aus der Timeline
2. Tippe auf "Zur Sammlung hinzufugen"
3. Wahle die passende Sammlung aus

Ein Sticker kann in mehreren Sammlungen liegen.

### Sammlungen verwalten

- **Umbenennen**: Tippe auf den Namen einer Sammlung
- **Neu sortieren**: Lange drucken und ziehen
- **Loschen**: Wische eine Sammlung nach links. Deine Sticker bleiben erhalten

## Leinwand

Die Leinwand ist dein kreativer Raum fur Collagen und Stickerwande.

### Eine Collage erstellen

1. Tippe auf den Tab Leinwand
2. Tippe auf "Neue Leinwand"
3. Tippe auf "Sticker hinzufugen"
4. Ziehe, skaliere und drehe jeden Sticker
5. Wahle eine Hintergrundfarbe oder Textur

### Tipps fur die Leinwand

- **Sticker stapeln**: So entsteht mehr Tiefe
- **Themenwande erstellen**: Nutze Sticker aus einer Sammlung fur einen einheitlichen Look
- **Exportieren und teilen**: Speichere dein Ergebnis als Bild oder teile es direkt

## Datenverwaltung

### Sammlung exportieren

Deine Daten gehoren dir. Du kannst deine ganze Sammlung jederzeit exportieren:

1. Gehe zu Profil → Daten
2. Tippe auf "Daten exportieren"
3. Wahle einen Speicherort
4. Nutze den Export fur Backups, Geratewechsel oder eine sichere Kopie

### Sammlung importieren

1. Gehe zu Profil → Daten
2. Tippe auf "Daten importieren"
3. Wahle eine zuvor exportierte Sicherungsdatei
4. Sticker und Sammlungen werden wiederhergestellt

### Hinweise zum Speicher

- Sticker werden auf deinem Gerat gespeichert. ButtSnap ladt nichts in die Cloud hoch
- Wenn du die App loschst, werden die in der App gespeicherten Sticker entfernt. Exportiere vorher ein Backup
- Die App selbst benotigt wenig Speicher; Platz brauchen vor allem deine Stickerbilder

## Pro-Abonnement

Die Kernfunktionen von ButtSnap sind kostenlos nutzbar, mit einem taglichen Kontingent fur Sticker-Erstellung. Wenn du mehr mochtest:

- **Unbegrenzte Sticker**: tagliche Aufnahme- und Erstellungslimits entfernen
- **Mehr Premium-Hintergrunde**: exklusive Hintergrundstile freischalten

Du kannst ButtSnap Pro abonnieren. Das Abo wird uber deine Apple ID verwaltet und kann jederzeit in den Systemeinstellungen gekundigt werden.
