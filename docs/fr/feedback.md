## Conseils pour un retour utile

### Signaler un bug

Veuillez inclure si possible :

- **Version iOS** : Reglages → General → Informations
- **Version de l'app** : page Profil de ButtSnap
- **Ce qui s'est passe** : decrivez l'action et le probleme
- **Resultat attendu** : ce qui aurait du se produire
- **Captures d'ecran** : utiles pour les problemes visuels ou de qualite de sticker

### Proposer une fonction

Vous pouvez expliquer :

- Ce que vous aimeriez faire avec vos stickers
- Comment la fonction s'integrerait a vos habitudes de collection ou de partage
- Les apps ou exemples qui vous ont inspire

Nous sommes une petite equipe, et chaque retour compte.
