# Utilisation de base

## Creer des stickers

ButtSnap transforme les moments du quotidien en stickers a collectionner.

### Prendre une photo

1. Ouvrez l'app : l'appareil photo apparait directement
2. Trouvez un sujet interessant, comme un petit souvenir, une fleur, une tasse ou un porte-cles
3. Visez le sujet et touchez le bouton de prise de vue
4. ButtSnap isole automatiquement le sujet, retire l'arriere-plan et ajoute un bord blanc avec une lueur douce
5. Votre nouveau sticker apparait aussitot dans la timeline

### Conseils pour de beaux stickers

- **Bonne lumiere** : la lumiere naturelle ou une scene bien eclairee donne les bords les plus propres
- **Sujet simple** : un sujet unique et bien distingue fonctionne mieux qu'une scene chargee
- **Main stable** : gardez l'appareil immobile pour un resultat plus net
- **Angles varies** : les petits objets sur une table rendent souvent tres bien en vue du dessus
- **Photos existantes** : vous pouvez aussi choisir une image dans votre phototheque

## Parcourir la timeline

Tous vos stickers sont automatiquement organises par date, comme un journal visuel.

### Vue Timeline

Sur la page principale, les stickers sont groupes par jour :

- Chaque date affiche les stickers crees ce jour-la
- Balayez pour parcourir les autres dates
- Revenez facilement sur les moments que vous avez collectionnes

### Voir les details d'un sticker

Touchez un sticker pour l'ouvrir. Vous pouvez alors :

- **Supprimer** : retirer un sticker qui ne vous convient pas
- **Ajouter a une collection** : classer le sticker dans une collection
- **Exporter** : enregistrer le sticker dans la phototheque ou le partager

## Partager vos stickers

- Ouvrez un sticker, puis touchez le bouton de partage
- Partagez-le via Messages, reseaux sociaux, ou enregistrez-le dans la phototheque
- Les stickers exportes conservent leur bord blanc et leur lueur douce
