# Fonctions avancees

## Collections

Les collections servent a regrouper des stickers lies par theme, pour organiser vos trouvailles et raconter de petites histoires.

### Creer une collection

1. Touchez l'onglet Collections
2. Touchez le bouton "+"
3. Donnez un nom a la collection, par exemple "Balade en ville", "Cafe" ou "Petites trouvailles"
4. Touchez "Termine"

### Ajouter des stickers

1. Ouvrez un sticker depuis la timeline
2. Touchez "Ajouter a une collection"
3. Choisissez la collection souhaitee

Un meme sticker peut etre ajoute a plusieurs collections.

### Gerer les collections

- **Renommer** : touchez le nom d'une collection pour le modifier
- **Reordonner** : appuyez longuement et faites glisser
- **Supprimer** : balayez une collection vers la gauche. Les stickers restent dans votre timeline

## Canvas

Le canvas est votre espace de creation pour assembler des stickers.

### Creer un collage

1. Touchez l'onglet Canvas
2. Touchez "Nouveau canvas"
3. Touchez "Ajouter des stickers"
4. Deplacez, pincez et faites pivoter chaque sticker
5. Choisissez une couleur ou une texture de fond

### Conseils Canvas

- **Superposez** les stickers pour creer de la profondeur
- **Creez un mur de stickers** avec une seule collection
- **Exportez et partagez** votre creation quand elle vous plait

## Gestion des donnees

### Exporter votre collection

Vos donnees vous appartiennent. Vous pouvez exporter toute votre collection :

1. Allez dans Profil → Donnees
2. Touchez "Exporter les donnees"
3. Choisissez un emplacement d'enregistrement
4. Utilisez l'export pour sauvegarder, migrer ou conserver une copie

### Importer votre collection

1. Allez dans Profil → Donnees
2. Touchez "Importer les donnees"
3. Selectionnez un fichier de sauvegarde exporte precedemment
4. Vos stickers et collections sont restaures

### Notes de stockage

- Les stickers sont stockes sur votre appareil. ButtSnap ne les envoie pas dans le cloud
- Si vous supprimez l'app, les stickers stockes dans l'app sont supprimes. Exportez une sauvegarde avant de reinstaller
- L'app elle-meme utilise peu d'espace ; ce sont surtout les images de stickers qui prennent de la place

## Abonnement Pro

Les fonctions principales de ButtSnap sont gratuites, avec un quota quotidien de creation de stickers. Si vous voulez :

- **Stickers illimites** : retirer la limite quotidienne de capture et de generation
- **Plus de fonds premium** : debloquer des styles de fonds reserves a Pro

Vous pouvez vous abonner a ButtSnap Pro. L'abonnement est gere par votre Apple ID et peut etre annule a tout moment dans les reglages de votre appareil.
