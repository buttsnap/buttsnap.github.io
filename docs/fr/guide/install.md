# Premiers pas

## Telechargement

ButtSnap est disponible sur l'App Store. Ouvrez l'App Store et recherchez "ButtSnap", ou touchez le lien ci-dessous.

[![Download on the App Store](https://developer.apple.com/assets/elements/badges/download-on-the-app-store.svg)](https://apps.apple.com/app/id6762453848)

## Configuration requise

- iOS 26.0 ou version ulterieure
- Compatible iPhone et iPad

## Premier lancement

### 1. Ouvrir l'app

Apres l'installation, touchez l'icone ButtSnap sur l'ecran d'accueil. Vous pouvez commencer a collectionner vos petits moments tout de suite.

### 2. Autoriser les permissions

Au premier lancement, l'app demande les permissions suivantes :

- **Appareil photo** : necessaire pour prendre vos photos. Touchez "Autoriser"
- **Phototheque** : necessaire pour enregistrer les stickers sur votre appareil. Touchez "Autoriser"

C'est tout. ButtSnap ne demande pas de compte, d'e-mail ni d'autres informations personnelles. Tout le traitement se fait sur votre appareil.

### 3. Commencer a collectionner

Visez quelque chose d'interessant et prenez votre premiere photo. ButtSnap cree automatiquement votre premier sticker.

Pour gerer votre abonnement ou exporter vos donnees plus tard, ouvrez la page Profil dans l'app.
